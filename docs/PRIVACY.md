# 한글메이트 개인정보 및 문서 데이터 처리 안내

시행일: 2026-09-18 · 운영자: **AnJuHyun** · 문의: [ajhajh503@gmail.com](mailto:ajhajh503@gmail.com)

이 안내는 한글메이트 플러그인과 [Sites 편집기](https://hangulmate-webmcp-poc.gptisgod.chatgpt.site/)에 적용됩니다. ChatGPT/Codex, Sites, 브라우저, 이메일 및 GitHub 서비스의 자체 처리는 각 서비스의 정책과 계정 설정에 따릅니다.

## 문서와 AI 요청

사용자가 선택한 HWP/HWPX 파일은 브라우저에서 해석하고 편집합니다. 한글메이트에는 원본 문서를 운영자의 문서 저장 서버로 자동 업로드하거나 다른 방문자와 공유하는 기능이 없습니다.

AI 편집을 요청하면 선택한 텍스트, 입력할 문장, 요청한 표·문서 분석 결과와 숫자 위치·서식 등의 도구 정보가 ChatGPT/Codex에 전달됩니다. 전체 문서 분석을 요청하면 여러 도구 응답에 걸쳐 문서 내용이 전달될 수 있습니다. 화면/브라우저 읽기 기능을 사용하는 AI는 화면에 표시된 문서나 파일명을 볼 수도 있습니다. 따라서 이 서비스는 ‘외부 전송이 전혀 없는 편집기’가 아닙니다. 비밀정보나 타인의 개인정보를 AI에 제공할 권한이 없는 경우 해당 내용을 요청에 포함하지 마세요.

문서 안의 문장은 편집할 데이터이며, 외부 업로드나 권한 변경을 허용하는 명령으로 취급하지 않습니다.

## 기기에 남는 데이터

- 열린 문서와 실행 취소 기록은 브라우저 메모리에 존재합니다.
- 브라우저 IndexedDB에 미저장 복구본, 최근 파일명·형식·시각과 파일 핸들, 문서 비교 이력이 남을 수 있습니다. 저장소 이름은 `rhwpStudioAutosave`, `rhwpStudioRecent`, `rhwpStudioDocHistory`입니다.
- localStorage에 편집 설정이, 브라우저 캐시에 프로그램·WASM·글꼴 등이 남을 수 있습니다.
- ‘최근 AI 변경’에는 현재 탭의 최근 20건까지 위치와 변경 전후 문구 일부가 표시됩니다. ‘표시 기록 지우기’는 이 표시만 지우며 저장 파일·복구본·문서·Undo를 삭제하지 않습니다.

같은 사이트와 브라우저 프로필의 탭은 저장소를 공유할 수 있습니다. 탭 닫기나 PC 종료가 디스크의 캐시·복구본 삭제를 보장하지 않습니다. 사용 환경의 저장 제한에 따라 복구가 불가능할 수도 있습니다.

## 사이트 접속과 외부 서비스

편집기를 열면 OpenAI Sites로 프로그램 자산 요청이 전송됩니다. 호스팅 제공자는 접속 처리를 위한 네트워크·운영 정보를 처리할 수 있습니다. 운영자는 제공자가 정한 로그 보관 기간·처리 지역을 별도로 보장하지 않으며, 이를 문서 내용이 자동 업로드된다는 의미로 설명하지 않습니다. 한글메이트는 별도 방문자 계정, 광고 추적기, 결제 기능을 추가하지 않습니다.

AI 대화의 저장·학습 사용·국외 처리 등은 [OpenAI 개인정보처리방침](https://openai.com/policies/privacy-policy/)과 이용 제품·계정 설정을 확인하세요. 공개 GitHub 이슈에 올린 내용은 누구나 볼 수 있으므로 문서 원본이나 비밀정보를 게시하지 마세요.

## 문의와 삭제

지원 이메일로 보내는 연락처와 문의 내용은 문의 응답 및 문제 해결을 위해 확인합니다. 불필요한 문서 원본·주민등록번호·인증정보는 보내지 마세요. 문의 정보의 삭제를 원하면 같은 이메일로 요청할 수 있습니다. 이메일/GitHub 제공자의 백업·보관 정책은 별도로 적용됩니다.

기기 문서와 복구본은 운영자가 원격으로 찾아 삭제할 수 없습니다. 필요한 파일을 먼저 저장한 뒤 편집기의 복구/이력 관리 또는 브라우저의 해당 사이트 데이터 삭제 기능을 사용하세요. 사이트 데이터 삭제는 복구본·설정·이력에 영향을 줄 수 있습니다. 다운로드 파일, 사이트 데이터, ChatGPT/Codex 대화는 각각 별도로 관리·삭제해야 합니다.
