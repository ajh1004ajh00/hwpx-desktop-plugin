## 시작과 지원 환경

[시작 안내](SITES-QUICKSTART.md)에 따라 플러그인을 설치하고 새 대화에서 ‘한글메이트 열어줘’를 요청하세요. 별도의 Node/Git/로컬 서버 설치는 필요하지 않습니다. AI 편집에는 WebMCP가 지원되는 Desktop 내장 브라우저가 필요합니다. WebMCP 미지원 브라우저에서는 직접 편집만 사용할 수 있습니다.

Windows의 자동 검사와 내장 브라우저 기능 시험을 진행했습니다. macOS는 별도 QA 결과가 확정되기 전까지 검증 완료 환경으로 표시하지 않습니다. 정확한 후보 버전과 남은 조건은 [제출 자료](https://github.com/ajh1004ajh00/hwpx-desktop-plugin/blob/main/docs/SUBMISSION.md)를 따릅니다. 앱 제품·버전·계정에 따른 기능 제공 범위는 해당 제공자의 조건에 따릅니다.

## 문제를 알려줄 때

OS/앱 버전, 파일 형식, 실행한 메뉴/요청, 기대 결과와 실제 결과를 알려주세요. 재현 자료가 필요하면 원본 대신 같은 문제가 발생하는 개인정보 없는 합성 문서를 준비하세요. 공개 이슈에 개인정보·기밀 문서·신분증·토큰을 붙이지 마세요. 보안 취약점과 비공개 문의는 이메일을 이용하세요. 응답 시간은 별도로 보장하지 않습니다.

## 편집·저장·복구

커서나 문서가 바뀌었다는 메시지가 나타나면 대상을 다시 선택하고 재요청하세요. AI 변경을 되돌릴 때는 문서 실행 취소를 사용하세요. 새로고침·탭 종료 전에는 파일을 저장하고 다시 열어 결과를 확인하세요. PDF는 브라우저 인쇄 창에서 PDF 대상을 선택하여 저장합니다.

복구본은 브라우저 저장소에 남을 수 있지만 반드시 복원된다고 보장하지 않습니다. 사이트 데이터 삭제 전에 필요한 문서를 파일로 보관하세요. ‘최근 AI 변경’ 표시 삭제와 복구본·다운로드 파일·AI 대화 삭제는 별개입니다.
