## 작업 방식

현재 WebMCP 5개 도구에는 서식 쓰기 도구가 없다. 서식은 기존 Studio 도구 모음과 Ctrl+Z/Ctrl+Shift+Z로 적용했고, read_selection → analyze_document의 formatRuns로 결과를 검증했다. WebMCP가 직접 서식을 변경한 것으로 기록하지 않는다. 저장한 신청서는 변경하지 않고 새 시험 문서를 사용했다.

최종 값: 맑은 고딕 / 16pt / bold=true / italic=true / underline=true / textColor=#000000. 1페이지. 실패·미실행 항목을 성공 처리하지 않으며 OPEN 유지.
