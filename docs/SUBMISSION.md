## 소개와 지원 창구

- 이름: 한글메이트 · HangulMate
- 한 줄 소개: 한글 문서의 문장과 표를 AI와 함께 읽고 수정하는 편집 도구.
- 설명: HWP/HWPX 문서를 브라우저 편집기에서 열고, 선택한 문장이나 현재 표 셀을 AI와 함께 작성합니다. 본문과 최상위 표를 분석하고, 지정한 구절을 찾아 수정하거나 선택 영역의 글자 서식을 변경할 수 있습니다. 문서 파싱과 표시는 브라우저에서 실행되며, 요청한 텍스트와 분석 결과는 AI 대화에 전달됩니다. 복잡한 문서의 호환성과 저장 결과는 확인이 필요합니다.
- 웹사이트: https://hangulmate-webmcp-poc.gptisgod.chatgpt.site/
- 지원 창구 초안: https://github.com/ajh1004ajh00/hwpx-desktop-plugin/issues (공개 게시판이므로 개인 문서·신분증·토큰을 첨부하지 않는다.)
- 개발자 표시명 초안: `ajh1004ajh00`. **검증된 신원과 일치하는 최종 표시명은 미확정**이다.
- 개인정보 안내 초안: [데이터 처리 기준](DATA-POLICY.md). 공개 개인정보처리방침·이용약관 URL과 운영 주체·지원 범위는 최종 확정 전이다.

## 시작 프롬프트

1. 한글메이트 열어줘.
2. 선택한 문장을 간결하게 바꿔줘.
3. 현재 표를 읽고 비어 있는 항목을 알려줘.
4. 문서에서 “참가 목적”을 찾아줘.
5. 선택한 글자를 16포인트, 굵게, 파란색으로 바꿔줘.

## 설치와 지원 범위

제출 유형은 Skills only를 기준으로 준비한다. `package-sites-plugin.mjs`로 만든 방문자용 ZIP을 사용한다. ZIP은 manifest, Skill, README, LICENSE, THIRD_PARTY_NOTICES, 데이터 처리 기준의 6개 파일이며 편집기 자산은 Sites에서 내려받는다. 사용자가 로컬 개발용 Node.js/Git/npm 서버를 설치할 필요는 없다.

2026-09-18 Windows의 이 작업을 실행하는 Desktop 내장 브라우저에서 공개 Sites의 WebMCP 8개 도구를 직접 확인했다. 특정 ChatGPT/Codex 제품·앱 버전·계정 전체에 대한 지원 보장은 아니다. 제품명/버전/계정 조건을 명시한 새 사용자 설치 시험과 심사자 환경에서의 재현은 아직 필요하다. 일반 Chrome에서는 직접 편집 가능·WebMCP 미지원 안내를 확인했다. macOS는 이번 시험에서 제외했다.

일반 본문 및 최상위 표 셀의 같은 문단 내 텍스트 편집과 선택 글자 서식을 지원한다. 중첩 표, 여러 문단/셀에 걸친 선택, 머리말/꼬리말 등은 지원 범위 밖이다. HWP/HWPX 저장 메뉴와 PDF 인쇄 메뉴가 있어도 출력 파일의 호환성 통과를 뜻하지 않는다.

## 정상 재현 사례

합성 문서만 사용한다. 새 문서 첫 문단이 `BODY_CONTROLS_UNSUPPORTED`이면 Enter로 일반 본문 문단을 만들고 시작한다. 쓰기는 매번 최신 `read_selection`의 snapshot과 새로운 command_id로 실행한다.

| ID | 사용자 요청·준비 | 기대 결과 | 2026-09-18 관찰 |
| --- | --- | --- | --- |
| P1 | 빈 일반 문단에서 현재 선택을 확인해줘 | selectedText가 빈 값, 쓰기 가능 여부를 구분 | 확인 |
| P2 | `앞문맥-A 선택내용-B 뒷문맥-C`에서 `선택내용-B`만 `검토완료`로 바꿔줘 | 앞뒤 문맥 유지, `앞문맥-A 검토완료 뒷문맥-C` | 확인 |
| P3 | 빈 문단에 위 합성 문장을 입력해줘. 동일 요청을 같은 command_id/인자로 재전송 | 한 번만 입력됨 | 확인 |
| P4 | 문서에서 `선택내용-B`를 찾아 선택해줘 | find_targets → focus_target → 새 read_selection의 선택 텍스트 일치 | 확인 |
| P5 | 선택한 구절만 16pt·굵게·취소선·#1266CC로 바꾸고 실행 취소해줘 | 선택 부분에만 적용, Undo 후 원래 서식 복원 | 확인 |
| P6 | 현재 일반 문단 전체를 `한글메이트 최종 합성 문장`으로 바꿔줘 | 문단 전체 교체, 문서 분석으로 결과 확인 | 확인 |

## 부정 재현 사례

| ID | 조작 | 기대 결과 | 2026-09-18 관찰 |
| --- | --- | --- | --- |
| N1 | snapshot을 읽고 UI로 커서를 옮긴 뒤 이전 snapshot으로 입력 | 수정하지 않고 CURSOR_CHANGED | 확인 |
| N2 | snapshot을 읽고 서식을 변경한 뒤 이전 snapshot으로 새 쓰기 | 수정하지 않고 DOCUMENT_CHANGED | 확인 |
| N3 | 기존 성공 command_id에 다른 입력 텍스트 전달 | COMMAND_REPLAY_MISMATCH, 추가 변경 없음 | 확인 |
| N4 | 한 줄 입력 도구에 줄바꿈 포함 `첫줄\n둘째줄` 전달 | 지원하지 않는 입력 거부, 문서 유지 | TOOL_FAILED와 문서 유지 확인. 구체적 오류 안내 개선 여지는 남음 |

정상 6개/부정 4개의 직접 관찰은 위 기능에 한정된다. 표 셀, 복잡한 문서, 실제 한글 IME, 파일 저장·독립 뷰어 재열기까지 통과한 것으로 확대하지 않는다. 최종 제출 파일과 실제 설치본이 같은지 해시·버전을 대조한 뒤 이 사례들을 다시 실행한다.
